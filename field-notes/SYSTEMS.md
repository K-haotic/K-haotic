## Read this map as responsibilities, not hype

Khaotic has mathematical research, experimental machines, source authority, distributed work, world construction and public interfaces. These layers connect, but **a dependency diagram is not a live deployment report**. The terms "body," "life," "recursion" and "world" can carry both technical and artistic meaning; evidence must say which meaning is being used.

| Layer / owner | Responsibility | Boundary |
| --- | --- | --- |
| **RPL / BHUAT** | Foundational questions, physical interpretation, mathematical inquiry, experiments. | Theory and interpretation are not self-validating. |
| **5FRE** | Ordered five-field recursive state, numeric experiments and controlled computation. | A model is not universal physical confirmation. |
| **LEVI** | Physical/native developmental-computing research, body-state continuity, firmware, multicore CPU, GPU and device integration. | Implemented subsystems and measured boot-specific results must be separated from pending admission. |

## Chronology is a feature, not clutter

The preserved internal history distinguishes:

1. **Origin and design:** what was imagined or specified, and when.
2. **Primary implementation:** source files, contracts and reviewed revisions.
3. **Measured execution:** exact packet, boot, test conditions or device.
4. **Custody and provenance:** source-generation admission, receipts, preservation and successors.
5. **Public projection:** a deliberately reduced view with no source-writer privilege.

A model's historical summary, a system's current source revision, and a physical machine's live status may differ. Treating any one as interchangeable with the others causes false progress reports and repeated hardware work.

## A practical release example

On **November 3, 2026**, the public Atlas progressed from a validated static release to a published crosswalk. An earlier deployment attempt detected unreadable public directory permissions and rolled back to the prior revision. The repair added exact public-path permissions, protected the private manifest, tested the actual Caddy service account's access before activation, and required local + public HTTPS proof before the source-controlled release was committed.

The published revision is visible at [khaotic.ai/REVISION](https://khaotic.ai/REVISION); the public graph and source crosswalk are at [Atlas](https://khaotic.ai/atlas/) and [Research Estate](https://khaotic.ai/atlas/research/#crosswalk). This example demonstrates why **continuity, evidence and recoverability** are system concerns rather than presentation features.
