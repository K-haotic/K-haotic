Try the exercises

Eight practical lessons

Read any lesson in any order. Examples are fictional unless attributed to an external source.

01 · The system

Model ≠ application

A model generates possible answers. The app may supply instructions, files, memory, retrieval, tools and rules. A fluent response alone doesn't tell you which components were used.

Try it

Ask an AI which information came from your message, which from an external source, and which is an inference. Verify the source yourself.

02 · Better requests

Give a clear task

Tell the AI your goal, relevant context, output format, constraints and what evidence would make the result trustworthy.

Try it

Change “Help with my budget” into “Using only these fictional expenses, group them into categories and flag missing values.” Never paste real account credentials.

03 · Context

What does the session know?

Information supplied in a conversation differs from model training. A long session can affect responses without changing a model's learned weights.

Try it

Compare the same question with no background, useful background and contradictory background. Ask the AI to identify uncertainty.

04 · Tools

Proposing is not doing

Writing “I sent the email” is not proof that software sent it. A real action requires a connected tool, appropriate permission and an observed result.

Try it

Ask what operation is proposed, whether it is authorized and what success receipt should exist before claiming completion.

05 · Memory & privacy

Know what you share

Session context, saved memory and external records are distinct. Storage and retention vary by service. Check the service's current settings and policies.

Try it

Use a fictional customer-support case. Decide what to keep, redact or omit before sharing with an AI service.

06 · Verification

Confidence isn't evidence

An answer can sound precise and still be incorrect. Find primary sources, check dates, confirm calculations and mark unknowns instead of guessing.

Try it

Choose a claim and ask for the exact source passage. If the source doesn't support it, revise the claim.

07 · Experiments

Test one change at a time

Compare a baseline and a revised prompt on the same task. Record the result, repeat it and include cases where your preferred approach fails.

Try it

Create five fictional questions and score both prompts on accuracy, missing evidence and work required. Five cases are a practice exercise, not a universal benchmark.

08 · Workflows

Make a small reliable loop

Plan → gather inputs → generate a candidate → verify → request permission for any real action → inspect the result. More agents or tools do not automatically mean better work.

Try it

Outline a source-backed report workflow with a human review before sending. Don't give a bot permanent access it doesn't need.
