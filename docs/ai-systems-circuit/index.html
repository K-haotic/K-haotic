Start with what matters

Less hype.
More capability.

AI literacy isn't memorizing buzzwords. It's learning to work with a tool while staying in control of the decisions and checking the evidence.

01 / ASK

Give the model a job.

Learn prompting, context, task breakdown and useful constraints. A well-framed request is often more valuable than a fancy prompt trick.

Try the Prompt Builder ↗
02 / VERIFY

Check what it says.

Separate the source from the guess. Learn to recognize missing information, false confidence and the difference between plausible and supported.

Try Evidence Detective ↗
03 / ACT

Keep your hands on the wheel.

Understand tools, permissions, memory and the proof that a real action happened. A bot saying “done” is not the same as a verified result.
