What you'll learn

  1. The model and the product. A neural network is not the whole application.
  2. Tokens, context and retrieval. What the model sees and what it doesn't.
  3. Session conditioning. Why a long conversation changes behavior without automatically retraining weights.
  4. Tools and guardrails. Which system actually carries out an action.
  5. Memory and privacy. Where information can live, and who controls it.
  6. Hallucination and verification. Check an answer against the source, not its appearance.
  7. Interactive tests. Learn through controlled, synthetic experiments.
  8. Build and pair instruments. Test how smaller and larger models, source retrieval, tool budgets and exact verification work together—and when coordinating models costs more than it helps.
